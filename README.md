---

## 🇯🇵 日本語:更新のしかた

1. 上のページを Chrome / Edge で開きます。
2. トラッカーをパソコンの USB に接続し、「**接続**」をクリックして、表示された一覧からトラッカーを選択します。
3. 最新のファームウェアは自動的に取得されます。手動で `.hex` ファイルを選ぶこともできます。
4. **トラッカーのボタンを押したまま**、「**更新を開始**」をクリックします。更新中はボタンを押し続け、USB を抜かないでください。
5. 「**更新が完了しました**」と表示されたら、ボタンを離してください。デバイスは自動的に再起動します。
6. 失敗した場合:ボタンを離し、USB を抜き差ししてから、再度ボタンを押したまま「もう一度試す」をクリックしてください。

---

## 🇬🇧 English: How to update

1. Open the page above in Chrome / Edge.
2. Connect the tracker to your computer via USB, click "**Connect**", and pick the tracker in the popup.
3. The latest firmware is fetched automatically; you can also select a `.hex` file manually.
4. **Press and hold the button on the tracker**, then click "**Start update**". Keep holding the button and do not unplug USB during the update.
5. When the screen shows "**Update complete**", release the button — the device restarts automatically.
6. If the update fails: release the button, unplug and replug USB, hold the button again and click "Try again".

## 🇹🇼 中文:如何更新

1. 用 Chrome / Edge 開啟上方網頁。
2. 將追蹤器接上電腦 USB,點「**連接裝置**」,在跳出的視窗中選擇追蹤器。
3. 網頁會自動抓取最新韌體;若失敗也可以手動選擇 `.hex` 檔。
4. **按住追蹤器上的按鈕不放**,點「**開始更新**」。更新過程中請一直按住按鈕、不要拔 USB。
5. 畫面顯示「**更新完成**」後,就可以放開按鈕,裝置會自動重新啟動。
6. 如果顯示更新失敗:放開按鈕,拔掉 USB 重新插上,再按住按鈕點「再試一次」。
